# بوت تليجرام شخصي — مساعد ذكاء اصطناعي

بوت **لمالك واحد** (owner-only) يجمع مزوّدات AI متعددة، ذاكرة دلالية،
بحث ويب، ووسائط متعددة — بواجهة أزرار كاملة بالعربية.

يتجاهل أي شخص غير `OWNER_ID` بلا رد.

## الميزات

| الميزة | التفصيل |
|---|---|
| **مزوّدات متعددة** | Anthropic · OpenAI · OpenRouter (افتراضي) · أي مزوّد متوافق مع OpenAI API |
| **اكتشاف النماذج** | جلب النماذج الفعلية من `/v1/models` مع كاش ساعة وزرّ تحديث |
| **تعدّد المفاتيح** | مفاتيح متعددة لكل مزوّد · دوري أو عشوائي · تبديل شفّاف عند الفشل · تعطيل تلقائي مع تنبيه |
| **مزوّد مخصّص** | Ollama · LM Studio · vLLM · LiteLLM — يُضاف بمحادثة من 4 أسئلة |
| **شخصيات** | إدارة كاملة بالأزرار · «مساعد عام» تُنشأ تلقائيًا |
| **ذاكرة RAG** | متجهات لكل رسالة · Atlas Vector Search أو حساب محلي · استرجاع تلقائي |
| **وسائط** | صور (Vision) · صوت (Whisper) — بنفس مسار المحادثة |
| **بحث ويب** | Serper أو Brave · كأداة تلقائية أو `/search` يدوي |
| **بثّ تدريجي** | الردّ يظهر أثناء توليده |
| **نسخ احتياطي** | تصدير JSON بضغطة · سكربت قابل للجدولة · استعادة |
| **تشفير** | مفاتيح API مشفّرة في Mongo (Fernet) |

## التشغيل محليًا

### 1. المتطلبات

- Python 3.11+ (المُوصى به 3.12 — `tgcrypto` قد لا يُبنى على 3.13)
- MongoDB (محلي أو [Atlas](https://www.mongodb.com/atlas) مجاني)
- Redis (اختياري — البوت يعمل بدونه بأداء أقل)

أسرع طريقة لقاعدتي البيانات:

```bash
docker run -d --name mongo -p 27017:27017 mongo:7
docker run -d --name redis -p 6379:6379 redis:7-alpine
```

### 2. التثبيت

```bash
cd telegram-ai-bot

python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### 3. الإعداد

```bash
cp .env.example .env
```

املأ الإلزامي:

| المتغيّر | من أين |
|---|---|
| `API_ID` · `API_HASH` | [my.telegram.org](https://my.telegram.org) → API development tools |
| `BOT_TOKEN` | [@BotFather](https://t.me/BotFather) → `/newbot` |
| `OWNER_ID` | [@userinfobot](https://t.me/userinfobot) — أرسل له أي رسالة |
| `MONGO_URI` | `mongodb://localhost:27017` محليًا |

**ثم أنشئ مفتاح التشفير** — هذا أهمّ خطوة أمنية:

```bash
python -c "from cryptography.fernet import Fernet;print(Fernet.generate_key().decode())"
```

ضع الناتج في `CONTENT_ENCRYPTION_KEY`. بدونه تُخزَّن كل مفاتيح
API نصًا صريحًا في Mongo.

وأخيرًا مفتاح مزوّد واحد على الأقل — [OpenRouter](https://openrouter.ai/keys)
أبسط بداية (يصل إلى موديلات Anthropic وOpenAI وGoogle بمفتاح واحد).

### 4. التشغيل

```bash
python main.py
```

أرسل `/start` لبوتك.

## التحقّق بعد أول تشغيل

هذه خطوات تحقّق عملية — أنصح بالمرور عليها بالترتيب:

```
1. /start                    → تظهر لوحة التحكّم
2. أرسل «مرحبًا»              → يأتي رد
3. أرسل «اسمي سالم»           → ثم «ما اسمي؟» → يتذكّر (السياق)
4. ⚙️ الإعدادات → 🤖 النموذج → اختر خدمة → تظهر نماذجها
5. 🔑 المفاتيح               → يظهر مفتاحك بآخر 4 رموز فقط
6. 🎭 الشخصيات → ➕ إضافة    → محادثة من سؤالين
7. أرسل صورة                  → يصفها (بنموذج بصري)
8. أرسل رسالة صوتية           → يُحوّلها ثم يجيب
9. /search آخر الأخبار        → نتائج بحث
10. 📦 تصدير                  → يصل ملف JSON
11. /status                   → كل الأرقام والحالات
```

## ربط Ollama محلي

```bash
ollama serve &
ollama pull llama3.2:3b

# تحقّق من التوافق قبل لمس البوت
curl http://localhost:11434/v1/models
```

أضفه من ⚙️ الإعدادات → 🔌 مزوّد مخصّص → ➕ إضافة، وأدخل
`http://localhost:11434/v1` كعنوان API و`-` كمفتاح (Ollama لا يتطلب مفتاحًا).

## الذاكرة الدلالية

```env
EMBEDDING_MODEL=nomic-embed-text
EMBEDDING_API_KEY=
```

البحث افتراضيًا **حساب تشابه محلي** على آخر 1500 عنصر — يعمل على أي
Mongo. لتسريعه على Atlas: أنشئ فهرس Vector Search باسم `memory_vectors`
على مجموعة `memories`، الحقل `vector`، ثم اضبط
`MEMORY_VECTOR_INDEX=memory_vectors`. البوت يسقط تلقائيًا للحساب
المحلي إن فشل الفهرس.

## تعدّد المفاتيح

كل مزوّد يقبل عدة مفاتيح. عند كل نداء يُختار واحد (دوري أو عشوائي)،
وعند فشله يُبدَّل تلقائيًا في نفس الطلب بلا أن تشعر.

**ما يُنسب إلى المفتاح فيُحسب عليه:** 401/403 (مصادقة) · 402 (رصيد) ·
429 (حصة).

**ما لا يُنسب إليه أبدًا:** المهلات · أخطاء 5xx. انقطاع عند المزوّد كان
سيُعطّل كل مفاتيحك السليمة خلال دقيقة، فتجد بوتك ميتًا بعد انتهاء
الانقطاع.

الـ **429 يُبرِّد** المفتاح دقيقة (أو حسب `Retry-After`) ولا يُعطّله:
مفتاح مزدحم مفتاح سليم. لكن ثلاثة 429 متتالية بلا نجاح بينها تُعطّله،
لأن حصة منتهية تُبلَّغ كـ 429 إلى الأبد. **أي نجاح واحد يصفّر العدّاد.**

## النسخ الاحتياطي

```bash
# نسخة كاملة (تحمل قيم المفاتيح — احفظها بأمان)
python scripts/backup.py

# بلا مفاتيح، مع تنظيف تلقائي
python scripts/backup.py --out /data/backups --keep 14 --no-secrets

# استعادة
python scripts/restore.py backups/backup-20260801-034100.json
```

للجدولة اليومية (crontab):

```cron
0 3 * * * cd /path/to/telegram-ai-bot && /path/to/.venv/bin/python scripts/backup.py --out /data/backups --keep 14 >> /var/log/bot-backup.log 2>&1
```

## النشر على Railway

المشروع يتضمّن `Dockerfile` و`railway.json` جاهزين:

```bash
railway init
railway up
```

اضبط متغيّرات البيئة نفسها الموجودة في `.env.example` من لوحة Railway،
واحرص أن `numReplicas` يبقى `1` — نسختان تعنيان جلسة تليجرام واحدة
يتنازع عليها عمليتان، وحلقة مفاتيح لكل نسخة، فتصير الاستراتيجية
الدورية عشوائية بلا إرادتك.

## ⚠️ ملاحظة مهمة

هذا الكود مُستخرَج من محادثة سابقة ولم يُشغَّل فعليًا في هذه الجلسة
(لا Mongo ولا Redis ولا مفاتيح API متاحة هنا). تم فحصه بصريًا وتدقيق
جميع ملفات Python نحويًا (`py_compile`)، وتم إصلاح قسم واحد
(`services/flows.py`) كان قد تلف أثناء التصدير الأصلي. أول تشغيل
حقيقي على جهازك هو ما سيكشف أي خلل لا يظهر بالتدقيق البصري — اتبع
قسم «التحقّق بعد أول تشغيل» أعلاه بالترتيب.

قائمة الموديلات في `services/catalog.py` وأسعار `PRICES` فيه تقديرية
وقد تكون قديمة؛ استخدم زرّ «الخدمات ← جلب النماذج» للحصول على القائمة
الفعلية من كل مزوّد.
